# PitcherStatTracker

PitcherStatTracker, also titled **Perfect Pitch** in the application window, is a Java Swing desktop application for tracking baseball pitcher statistics. The program lets users create pitcher profiles, record pitching sessions, enter pitch outcomes, and view calculated pitching statistics.

## Features

- Create and manage pitcher profiles
- Record pitching sessions
- Track pitch results such as hits, walks, strikeouts, and outs
- Calculate pitcher statistics across sessions
- View pitcher information through a Java Swing interface
- Navigate between login, pitcher list, pitcher profile, session, and stat display screens
